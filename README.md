# Liga 3 Colinas — Portal

Portal público de competições esportivas, voltado à organização de temporadas, calendário, classificação e identidade das divisões.

## Tecnologias
Next.js e integração com serviços de gestão esportiva.

## Minha atuação
Definição de requisitos, regras de competição, experiência do usuário, prototipagem assistida por IA e validação funcional.

## Projeto relacionado
[L3C Stats](../l3c-stats) e [L3C API](../l3c-api). Consulte a documentação operacional abaixo para o estado da implantação.

---

## Referência operacional preservada

### l3c-portal

Portal público da Liga 3 Colinas (Next.js)

Este repositório receberá o código do portal aprovado atualmente publicado em `liga3colinas.com.br`. **Nenhuma versão está implantada automaticamente a partir deste repositório.**

Fluxo planejado: `feature/*` → revisão/PR → `main` → homologação → implantação manual autorizada.

Pontos obrigatórios: preservar a home aprovada, temporada 2027, identidade Elite/Acesso, liga Master 2026, SEO e integrações legadas.

**Não enviar:** `.env` real, tokens, segredos, backups SQL, arquivos de sessões ou banco.
