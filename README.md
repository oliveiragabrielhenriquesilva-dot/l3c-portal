# l3c-portal

Portal público da Liga 3 Colinas (Next.js)

Este repositório receberá o código do portal aprovado atualmente publicado em `liga3colinas.com.br`. **Nenhuma versão está implantada automaticamente a partir deste repositório.**

Fluxo planejado: `feature/*` → revisão/PR → `main` → homologação → implantação manual autorizada.

Pontos obrigatórios: preservar a home aprovada, temporada 2027, identidade Elite/Acesso, liga Master 2026, SEO e integrações legadas.

**Não enviar:** `.env` real, tokens, segredos, backups SQL, arquivos de sessões ou banco.
